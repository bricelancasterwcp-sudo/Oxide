```rust
fn main() {
    let mut n = 27;
    
    while n > 1 {
        if n % 2 == 0 {
            n /= 2;
        } else {
            n *= 3 + 1;
        }
    }
    
    println!("Total transformations: {}", n);
}
```

### Explanation:
- We start with the number `n = 27`.
- We use a `while` loop to repeatedly perform the transformation until `n` becomes 1.
- Inside the loop, we check if `n` is even or odd using the modulus operator `%`.
  - If `n` is even, we divide it by 2 and update `n` accordingly.
  - If `n` is odd, we multiply it by 3 and add 1 to `n`.
- Finally, we print the total number of transformations performed.
