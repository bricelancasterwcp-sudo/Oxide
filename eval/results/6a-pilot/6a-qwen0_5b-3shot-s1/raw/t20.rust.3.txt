```rust
fn main() {
    let mut p = 1;
    for i in 1..7 {
        p *= i;
    }
    println!("{}", p);

    // Define the items with their prices and quantities
    let pen = (3, 4);
    let pad = (9, 2);
    let ink = (5, 3);

    // Calculate the combined cost of all items
    let combined_cost: i64 = pen.0 * pen.1 + pad.0 * pad.1 + ink.0 * ink.1;

    // Find the item with the highest cost
    let mut max_item = pen;
    if pad.0 > max_item.0 && pad.0 > max_item.1 {
        max_item = pad;
    }
    if ink.0 > max_item.0 && ink.0 > max_item.1 {
        max_item = ink;
    }

    println!("{}", combined_cost);
    println!("Item with the highest cost: {}", max_item);
}
```

### Explanation:
- **Loop through numbers**: The `for` loop iterates from 1 to 6.
- **Multiply products**: Each number is multiplied by its corresponding quantity in the list (`pen`, `pad`, and `ink`).
- **Calculate combined cost**: The sum of all these products is stored in `p`.
- **Find maximum item**: The program finds the item with the highest price by comparing the quantities of each item.
- **Print results**: Finally, it prints both the combined cost and the item with the highest cost.
