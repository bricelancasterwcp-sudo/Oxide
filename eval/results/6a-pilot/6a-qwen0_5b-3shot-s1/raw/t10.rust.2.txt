```rust
fn main() {
    let nums = vec![4, 1, 7, 3, 9, 2];
    
    // Filter out numbers greater than 3
    let filtered_nums: Vec<i32> = nums.into_iter()
        .filter(|&n| n > 3)
        .collect();
    
    // Sort the remaining numbers in descending order
    filtered_nums.sort_unstable_by(|a, b| b.cmp(a));
    
    // Print each kept value on its own line preserving their original order
    for &num in filtered_nums {
        println!("{}", num);
    }
    
    // Count how many values were kept
    let count = filtered_nums.len();
    println!("Number of values kept: {}", count);
}
```

### Explanation:
1. **Filtering**: We use `filter` to keep only the numbers greater than 3.
2. **Sorting**: We sort the remaining numbers in descending order using `sort_unstable_by`.
3. **Printing**: Each kept value is printed on its own line, preserving their original order.
4. **Counting**: The length of the filtered vector gives us the number of values that were kept.
