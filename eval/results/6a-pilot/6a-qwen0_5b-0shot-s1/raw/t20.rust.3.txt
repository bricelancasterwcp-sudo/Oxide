```rust
fn main() {
    let mut pen = 3;
    let pad = 9;
    let ink = 5;

    // Calculate the total cost of the items
    let total_cost = pen * 4 + pad * 2 + ink * 3;

    // Determine which item has the highest cost
    let max_cost_item = if pen > pad && pen > ink { "pen" } else if pad > pen && pad > ink { "pad" } else { "ink" };

    // Print the results
    println!("Total cost: {}", total_cost);
    println!("Item with the highest cost: {}", max_cost_item);
}
```

3. **Finding the Item with the Highest Cost**: We use a simple conditional statement to determine which item has the highest cost:

   - If `pad` is greater than both `pen` and `ink`, `max_cost_item` is set to "pad".
   - If neither condition is met, `max_cost_item` is set to "ink".
