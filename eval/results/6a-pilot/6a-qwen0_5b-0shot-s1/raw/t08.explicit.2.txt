```
fn main() {
    let num_values = vec![3, 8, -2, 12, 7];
    let count_positive = num_values.into_iter().filter(|&value| value > 0).count();
    println!("Count of positive values: {}", count_positive);
    println!("Largest value: {}", *num_values.iter().max().unwrap());
}
```

**Explanation:**

- The program reads a vector of integers `num_values` into a new vector `v`.
- It counts the number of positive numbers in `v` using the `filter` method with a closure that checks if each number is greater than zero.
- It then uses the `max` method to find the largest value in `v`.
