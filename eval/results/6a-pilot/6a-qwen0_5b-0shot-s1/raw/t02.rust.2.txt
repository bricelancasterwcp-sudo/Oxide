fn main() {

    let num = 27;

    while num != 1 {

            num /= 2;

            num *= 3;
            num += 1;
        }
        count += 1;
    }

    println!("Total transformation steps: {}", count);
}

3. **Transformations**:

4. **Increment Count**: Each transformation increments the `count`.

5. **Output**: After each transformation, we print the current value of `count`.
