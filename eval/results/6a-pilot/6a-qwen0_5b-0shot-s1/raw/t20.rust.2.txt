```rust
fn main() {
    let mut pen = 3;
    let pad = 9;
    let ink = 5;

    // Calculate the total cost of the items
    let total_cost = pen * 4 + pad * 2 + ink * 3;

    // Determine which item has the highest cost
    let max_cost_item = if pen > pad && pen > ink { "pen" } else if pad > pen && pad > ink { "pad" } else { "ink" };

    // Print the results
    println!("Total cost: {}", total_cost);
    println!("Item with the highest cost: {}", max_cost_item);
}
```

### Explanation:
1. **Variables**: We define three variables `pen`, `pad`, and `ink` to represent the costs of the pen, pad, and ink items, respectively.

2. **Total Cost Calculation**: We use a simple loop to calculate the total cost by multiplying each item's unit price by its quantity. The result is stored in the variable `total_cost`.

3. **Finding the Maximum Cost Item**: We compare the total cost of each item with the maximum cost found so far (initialized as `"pen"`) and update the maximum cost if a higher value is found.

4. **Output**: Finally, we print the total cost and the name of the item with the highest cost.
