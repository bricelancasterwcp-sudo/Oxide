# Perfect Numbers

In this task, you need to write a Rust program that prints out all perfect numbers greater than 0 and less than 1000 in increasing order, one per line. A perfect number is a positive integer that is equal to the sum of its positive divisors other than itself.

```rust
fn main() {
    for x in range(2, 1000) {
        let sum = divisors_sum(x);
        if sum == x {
            print(x);
        }
    }
}

fn divisors_sum(n: Int) -> Int {
    let mut sum = 0
    for i in range(1, n) {
        if n % i == 0 {
            sum = sum + i
        }
    }
    sum
}
```

In the provided solution, we first define a function `divisors_sum` that takes an integer `n` as input and returns the sum of its positive divisors. We then use a `for` loop to iterate over the range of numbers from 2 to 1000. For each number, we call the `divisors_sum` function to calculate the sum of its divisors. If the sum is equal to the number itself, we print it out.
