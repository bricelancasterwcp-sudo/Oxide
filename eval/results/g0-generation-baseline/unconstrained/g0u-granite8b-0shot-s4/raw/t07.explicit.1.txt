```
fn main() {
    let mut v = vec();
    for i in range(1, 9) {
        if i % 3 == 0 {
            v = push(v, i);
        }
    }
    let sum = sum(&v);
    print(sum);
    drop sum;
    drop v;
}

fn sum(v: &Vec<Int>) -> Int {
    let mut acc = 0;
    for x in &v {
        acc = acc + x;
    }
    acc
}
```

The `sum` function consumes its argument, then the caller consumes the
result, then the caller drops the result, then the caller drops the
argument. The last `drop` is at the end of the defining block of the
function, so the checker can see the `sum` is dropped and `v` is still alive
at that point.
