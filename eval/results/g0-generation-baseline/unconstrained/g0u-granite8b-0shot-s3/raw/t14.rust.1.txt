```rust
fn main() {
    let text = "mississippi";
    let s_count = text.matches('s').count();
    let distinct_chars = text.chars().unique().count();
    println!("Number of 's': {}", s_count);
    println!("Number of distinct characters: {}", distinct_chars);
}
```

Output:
```
Number of 's': 4
Number of distinct characters: 11
```
